# Hadramout Cards

Repository for the Hadramout Cards Windows application.

## Restoration status

The available v1.1.3 x64 Portable distribution contains a partial Python source snapshot. The original Git history, CI workflows, packaging scripts and automated test suite have not yet been restored.

**Do not treat this repository as a verified production build.** Recovered code must be reviewed, tested on Windows and packaged through test-first CI before it is merged into `main`.

The recovery work should be performed in a separate `recovery/v1.1.3-x64` branch. Do not place private credentials, local customer data or activation signing secrets in source control.
